# GENERAL GUIDELINES FOR CONTRIBUTING TO THE TEXTTOKLATTSCH PROJECT
- Under no circumstances should AI assistant tools of any kind (programming, design, etc.) be used in any fork of the TextToKlattsch Project; Humans work on software for Humans, keep AI away from my code.
    - Examples of AI assistant tools: ChatGPT, Claude, OpenAI Codex, Google Gemini, Microsoft Copilot, Github Copilot
- Do not use anything of the original creator's to advertise projects outside the scope of TextToKlattsch.
- DO NOT FEED THIS REPOSITORY TO ANY FORM OF LLM OR OTHER MACHINE LEARNING ALGORITHMS. EVEN PRIVATELY HOSTED ONES.
